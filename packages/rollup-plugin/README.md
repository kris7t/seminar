# @seminar/rollup-plugin

Rollup and Vite plugin for Seminar presentations.

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

The MDX compilation plugin shared by the Rollup and Vite integrations.
For HTML pages, live updates, and self-contained builds, use `@seminar/vite-plugin`.
