# @seminar/plugin-pele

Mermaid diagrams in Seminar decks, rendered with
[Pele](https://pele.run).

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

Enable diagrams with `seminar({ plugins: ['@seminar/plugin-pele'] })` in
`@seminar/vite-plugin`.
