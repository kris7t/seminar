# @seminar/theme-default

Default theme of Seminar presentations with the Roboto font.

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

The default theme used by `@seminar/vite-plugin`, including the Roboto font
for offline presentations. Import it as a starting point for a custom theme.
