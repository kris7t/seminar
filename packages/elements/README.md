# @seminar/elements

Reusable presentation elements for Seminar decks.

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

Enable the callout and column directives with `seminar({ plugins: ['@seminar/elements'] })`
in `@seminar/vite-plugin`. React components are also exported directly.
