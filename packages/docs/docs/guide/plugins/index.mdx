# Plugins

Plugins extend Seminar with new slide components, Markdown syntax, and
compiler features. Enable the plugins you need in your
[project configuration](../getting-started.md#add-presentation-features).

You can also [develop your own plugins](../../developer/plugins.md) to add
features for your presentations or share them with others.
