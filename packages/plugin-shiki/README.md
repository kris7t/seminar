# @seminar/plugin-shiki

Syntax highlighting of code blocks in Seminar decks with Shiki.

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

Enable syntax highlighting with `seminar({ plugins: ['@seminar/plugin-shiki'] })`
in `@seminar/vite-plugin`.
