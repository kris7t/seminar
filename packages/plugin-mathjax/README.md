# @seminar/plugin-mathjax

Math in Seminar decks, typeset with MathJax when decks are compiled or in the browser.

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

Enable math with `seminar({ plugins: ['@seminar/plugin-mathjax'] })` in
`@seminar/vite-plugin`. For formulas that change while presenting, use the
`DynamicFormula` component from `@seminar/plugin-mathjax/dynamic`.
