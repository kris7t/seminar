# @seminar/mdx

MDX support for Seminar presentations.

Part of [Seminar](https://seminar.run), a toolkit for scientific talks and
lectures as Markdown presentations. Requires Node.js 24 or newer.

Compiles `.deck.mdx` presentations with remark, rehype, and recma plugins.
For a complete Vite integration, use `@seminar/vite-plugin`.

Add `@seminar/mdx/client` to your TypeScript `types` for deck module declarations.
